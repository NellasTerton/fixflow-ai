# FixFlow AI: продукт

## Что это

FixFlow AI — публичный портфолио-проект. Он демонстрирует работу AI-диспетчера
и CRM вымышленной выездной сервисной компании. Это не система для обработки
реальных клиентов.

Компания оказывает три вида услуг:

1. ремонт бытовой техники;
2. сантехнические работы;
3. установка и обслуживание кондиционеров.

## Главный демонстрационный сценарий

Клиент пишет в чат → система определяет категорию → использует RAG для ответа →
собирает контактные данные → предлагает время → создаёт заявку → показывает её
в публичной CRM → отправляет webhook → Make/n8n запускает Telegram-уведомление
и отложенный follow-up.

Сейчас реализована первая половина этого пути: гибридный чат использует Claude
для классификации и извлечения данных, а детерминированный сервер проверяет
поля, сохраняет сообщения в Neon, создаёт заявку, бронирует слот и сразу
показывает результат в CRM. При ошибке LLM сценарий продолжает работать без
неё. RAG отвечает на информационные вопросы только по демонстрационной базе
знаний и показывает источники. Внешняя автоматизация остаётся следующим
этапом.

## Пользователи

- Посетитель портфолио проходит клиентский сценарий.
- Посетитель CRM видит, как заявка меняется на разных этапах.
- Разработчик или нанимающий менеджер оценивает архитектуру и автоматизацию.

## Ограничения демо

- Полноценной авторизации сотрудников пока нет.
- `/demo/crm` доступна публично без логина и только для чтения.
- Реальные персональные данные запрещены.
- Телефоны и адреса в демо маскируются.
- Neon PostgreSQL и pgvector подключены; Claude включается через server-only
  env, а RAG использует только `.md`/`.txt` demo-документы. Внешние API
  автоматизаций пока не используются.

## Критерий успеха первой версии

Посетитель может безопасно пройти весь вымышленный путь от сообщения до заявки,
увидеть результат в CRM и понять, где Next.js заканчивает работу, а внешняя
автоматизация начинает её.
