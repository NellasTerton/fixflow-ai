# Скриншоты для README

Файлы ниже подставляются в корневой `README.md`. Разрешение — ширина
1200–1600px, формат PNG, десктопная раскладка (кроме отдельно оговорённого).

## `homepage.png`

`https://fixflow-ai-kappa.vercel.app/`

Верхняя часть страницы (hero): заголовок «Мастер приедет тогда, когда вам
удобно», три цифры (12/90/12), встроенный чат-виджет справа. Перед снимком
можно кликнуть один из quick-starter'ов («Стиральная машина не сливает
воду»), чтобы в чате уже был виден один обмен репликами — так виджет
выглядит живым, а не пустым.

## `chat.png`

`https://fixflow-ai-kappa.vercel.app/chat`

Пройти диалог свободным текстом до момента, когда виден баннер «Заявка
FF-XXXX создана» поверх поля ввода — важно показать естественный диалог
(без кнопок выбора, их в интерфейсе больше нет с D-030) и то, что после
создания заявки переписка не обрывается.

## `workspace.png`

`https://fixflow-ai-kappa.vercel.app/workspace/leads`

Полная Kanban-доска: видно несколько колонок (Новые / Запланированы / В
работе / Выполнены) с карточками — имя клиента, район, цена.

## `lead-detail.png`

`https://fixflow-ai-kappa.vercel.app/workspace/leads/<id>` — id любой заявки
из списка `/api/workspace/leads`, лучше с непустым разделом AI runs.

Прокрутить до блока «Почему AI так ответил?» — важно, чтобы было видно хотя
бы одну запись хода диалога (модель, длительность, итоговый ответ агента).

## Необязательно, но хорошо смотрится

- `automations.png` — `/workspace/automations`, видно несколько записей
  `delivered` с HTTP 200.
- `mobile.png` — главная страница на мобильной ширине (375px), показывает
  адаптивность.
