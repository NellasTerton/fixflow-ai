## Версия для раздела «Проекты»

**FixFlow AI — AI-диспетчер и операционная система для выездных сервисных
компаний.** Публичный pet-проект, доведённый до продакшена: клиент пишет в
чат, что сломалось, AI определяет направление и услугу, отвечает по базе
знаний компании через RAG, собирает контакты, предлагает свободное время и
создаёт заявку — она сразу видна диспетчеру и уходит через Make в Telegram.

- Спроектировал и реализовал гибридную архитектуру: LLM только предлагает
  (классификация, извлечение данных, формулировка вопроса), а
  детерминированный сервер независимо валидирует каждое поле и решает,
  какое действие разрешено — доступность внешнего provider не влияет на
  возможность оформить заявку.
- Построил RAG-контур на Neon pgvector с локальными детерминированными
  embeddings, HNSW cosine-индексом и grounding-проверкой: модель не может
  придумать цену, гарантию или зону обслуживания при отсутствии источника
  в базе знаний.
- Спроектировал схему PostgreSQL (16+ таблиц, Drizzle ORM) с check
  constraints, безопасным поведением при удалении и атомарными SQL-CTE для
  конкурентного бронирования слотов без гонок.
- Подключил внешний контур автоматизаций через Make.com: маршрутизация
  webhook-событий по типу, идемпотентный callback, отложенные бизнес-события
  (follow-up, напоминания) без cron внутри приложения — обнаружил и
  диагностировал причину дублирующихся уведомлений через API Make
  напрямую и исправил на уровне blueprint сценария.
- Провёл самостоятельный технический аудит production после первой версии:
  нашёл и исправил нерабочий фильтр по сроку жизни данных, утечку
  внутреннего служебного маркера в эмбеддинги RAG и несогласованность
  формата телефона со страной сервиса.

**Стек:** Next.js 16 (App Router, TypeScript), Tailwind CSS, shadcn/ui,
Drizzle ORM, Neon PostgreSQL + pgvector, Claude Messages API, Vitest,
Netlify, Make.com.
